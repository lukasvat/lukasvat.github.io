Marble Maze Mobile

Swift - Xcode

Marble Maze Mobile is a 2D labyrinth game for iOS where players use intuitive tilt controls to navigate a ball through a maze. This project showcases a clean Model-View-Controller (MVC) architecture and integrates key Apple frameworks to deliver a complete user experience. CoreMotion is leveraged to translate the device's physical tilt into in-game movement, while SpriteKit powers the 2D graphics, animation, and physics-based collision detection. For robust data persistence, Core Data is implemented to save all player statistics, high scores, and customization settings, ensuring a continuous and personalized experience across sessions.
